# 2026-10-08：原生布局、SIMD 栅格扫描与紧凑匹配

本轮以 `4241b36` 为基线，目标是完整分解的较坏输入耗时。输入输出布局可自由选择，整体仍守住 `O(n³)`。`C:\WorkSpace\voxel_engine\crates\voxel_mesh` 只作上下游参考，没有修改该 crate；下列数字不代表完整引擎或 GPU 性能。

## 保留的实现

1. 匹配的 CSR 偏移、转置写入／长度 3 增广游标和显式 DFS 栈改为 u16，访问切片时转换为 usize。64×64 的每方向 chord ≤1953、边 ≤3969，静态断言保护容量，没有截断。匹配算法与邻居顺序不变。
2. 新增 `DenseLabels64`，行主序 `[[u16; 64]; 64]`，8192 B，64 B 对齐，0 为背景。已有切面可直接进入后端，省去单位 leaf 列表和 shape／overlap 校验；任意 u16 标签组合都合法。
3. 相邻像素／行用 `u16x32` 比较，数据向量逻辑宽度 512 bit。横向两次重叠比较覆盖全部 1..63 边界；相邻行差异位图同时驱动列 run 收尾，省去完整转置和逐像素列扫描。无变化的行共享已生成区间。
4. leaves 少于 512 时保留原事件桶，至少 512 时栅格化再扫描。全单位输入直接检查目标标签格是否已占用；混合 LOD 用行占用位图检查重叠后填充标签。形状验证、容量保护和错误返回仍保留。
5. `decompose_into`／`decompose_labels_into` 直接从分区阶段调用消费者，不写 scratch 内的 AoS 矩形数组。`PackedRectangles64` 使用 64 B 对齐的 bounds u32 数组＋labels u16 数组，最多4096项，24640 B；`repr(C, align(64))` 保证两个数组起点的对齐。每个 bounds 的四字节是 x.start、x.end、y.start、y.end，终点 64 可表示。

直接 sink 与借用输出顺序一致。输入验证失败不会调用 sink；callback 错误立即终止，已输出前缀及失败 callback 的副作用不回滚，scratch 可继续复用。packed 调用先清长度，失败保留本次前缀。

紧凑匹配单独将 scratch 从326336 B降至256048 B（-21.54%）；加上8192 B栅格与对齐后，最终为 **264256 B（约258 KiB，较基线-19.02%）**。零堆分配接口保持原契约；调用方的输入／packed 输出／callback 存储另计。

## 复杂度与选择布局

合法 dyadic leaves 不重叠，每片面积至少1，因此 `L≤n²`、所有 leaf 面积之和≤n²。混合 LOD 栅格化的填充总工作≤n²，行占用更新的跨度之和也≤n²；单位路径两次遍历为 O(L)。栅格清零和 SIMD 轴构建为 O(n²)，行列最大区间数量均≤n²。原 HKDW 继续为 `O((C+E)√C)`，几何约束给出 `C,E=O(n²)`，整体为 **O(n³)、空间 O(n²)**。

512 是当前固定尺寸的路径选择阈值，非理论必要条件。最初256阈值与通用 raster 导致部分单位输入回退；改为单位直接占用检查和512阈值后，最终重复测量如下。少量大 LOD 适合事件输入，强制原生 grid 反而增加扫描。上游大量单位面可直接填写 grid；下游立即构建 mesh 可使用 sink，但省掉中间数组不等于每种消费者都加速。

参考引擎当前按 layer 输出无序 dyadic leaves，使用共享 palette，将分解矩形再复制到 layer 结果；最终 CompactSurface 仍包含顶点去重和材质打包。新布局可减少相邻阶段的数据整理，不能直接省掉这些后续工作。

## 测量方法与原始数据

Rust 1.100.0-nightly（67eda617e，2026-09-10），LLVM23.1.1，Windows x86_64 MSVC；CPU标识 Intel64 Family6 Model183 Stepping1。本机支持AVX2，不支持AVX-512。默认 release 与 `-C target-feature=+avx2` 分别构建，同一组基线／候选使用相同 ISA。逻辑 CPU2固定亲和；没有其它基准或编译并行执行。

同一进程包含两份库，scratch及输入在计时外构造，ABBA／BAAB交替；一般入口每阶段64次、41轮，两次独立重复。数据表为每轮 `(候选/基线−1)` 的中位数，负数更快；不是绝对中位数的直接相除。完整CSV包含IQR与绝对时间，存于 [data/nextopt-2026-10-08](data/nextopt-2026-10-08/)。只比较本轮增量，不能与历史百分比相加。

- `leaves`：两侧都从同一 leaf 列表开始，候选包含自动栅格转换。
- `native_grid`：基线从 leaf 列表开始，候选的grid在计时外已就绪。体现上游原生布局的潜力，转换成本不在此列。
- `producer_pipeline`：基线从共同的已知合法 square 记录填充复用 leaf Vec；候选清零并填写复用 grid，然后完整分解。共同的上游遍历、可见面判断、palette 构建未计入。
- `consume_pipeline`：基线复制借用输出到复用 bounds／material Vec；候选从 leaves 直接写同一种 Vec。包含同样的 u16 标签到 u32 材质查表，不包含顶点去重或 GPU 上传。

计时外检查基线／leaves／grid的完整有序 Rectangle序列相等，简单图案另查已知最优数；消费者读取／保存实际范围和标签，失败会终止程序。返回切片或结果缓冲经过 black_box，避免仅保留数量而删除输出工作。

## 匹配的 SIMD／几何试验

另做了几何位集greedy、几何HK、恢复degree rank的seed及ordered DFS。它们维持n³，却没有稳健的较坏输入收益：几何HK在低差异孔洞快约7–12%，dense_random慢约11–15%；ordered版本在两组孔洞继续回退。最终只合入紧凑索引，继续使用原CSR HKDW。算法、phase计数、容量与拒绝依据见 [几何匹配记录](geometric-matching-2026-10-08.md)。

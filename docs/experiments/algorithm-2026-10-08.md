# 2026-10-08：区间位图与增广游标实验

基线算法为 `81f4a43`，候选为本次工作区改动。两者使用同一组新增的确定性基准输入、同一工具链和 release 配置。`rustc --version` 报告 `1.100.0-nightly (67eda617e 2026-09-10)`，平台为 Windows x86_64。

本页记录第一阶段候选的历史结果；Builder、LOD 展开、scratch 大小和基准覆盖随后继续改动，当前结构及后续结果见 [非匹配阶段实验记录](nonmatching-2026-10-08.md)。

## 改动与不变量

- 行列桶用起点直接索引和 `u64` 有效位图取代比较排序。有序枚举同时检查重叠、合并同色相邻区间；单个叶子仍只向各行列展开一个区间。leaves／image 的构造上界从 `O(n² log n)` 降为 `O(n²)`，builder 保留原排序路径。
- 长度 3 增广为匹配左顶点维护单调邻接游标，复用转置构造后的 `write_offsets`。预热期间已占用右顶点不会变回空闲，因此每条内层邻接边最多检查一次；预热上界从 `O(C+E+EΔ+n)` 降为 `O(C+E+n)`，配对选择与原实现一致。
- 整体精确分解仍为 `O(n³)`，空间仍为 `O(n²)`；HKDW 搜索没有修改。scratch 实测从 334,144 增至 334,912 字节，增加 768 字节，约 327 KiB。

## 测量方法

Criterion 覆盖原含孔图、image 构造、scratch 初始化，以及九类图案的 leaves／image 两个借用入口。原版和候选可执行文件分别保存后交替运行。早期同一原版程序也出现接近一倍的耗时变化，固定 CPU 亲和性后的较长测量仍有严重离群值，因此不把首轮约 50% 的差异归因于算法。

最终追加同一进程中的成对测量：同时编译两份算法，输入、image、scratch 在计时外构造；每个阶段连续调用 64 次，以 ABBA／BAAB 顺序交替测量。每个输入和入口运行 41 轮，两次完整重复，并把进程固定在逻辑 CPU 2。下表是每轮 `(候选耗时 / 基线耗时 - 1)` 的中位数，负值表示加速；斜线分隔两次重复。不同输入的百分比不能直接相加。

| 输入 | leaves 变化 | image 变化 |
| --- | ---: | ---: |
| 原低差异含孔图 | -3.51% / -3.22% | -4.83% / -2.44% |
| 单个大 LOD 叶子 | +4.74% / +5.12% | +4.42% / +5.04% |
| 规则块 | +0.15% / -2.07% | -2.22% / -2.37% |
| 条纹 | +4.78% / -2.52% | +1.54% / -2.50% |
| 双色棋盘格 | -2.54% / -2.69% | -1.81% / -2.47% |
| 最大 chord 交替孔洞 | -0.35% / -0.39% | +0.18% / +0.12% |
| 稀疏随机 | -0.85% / -1.10% | -1.33% / -0.18% |
| 密集随机孔洞 | -1.60% / -3.40% | -1.25% / +0.41% |
| 大量小颜色组 | +1.02% / +1.58% | -0.64% / +1.54% |
| 逆序单位像素 | -9.90% / -9.46% | -4.47% / -5.34% |

逆序单位像素的 leaves 入口收益最清晰：两次中位耗时分别为 26.534→23.920 µs、26.123→23.727 µs，成对变化的中间 50% 范围均处于加速侧。原含孔图的中位数略有改善，但多数样本的成对波动仍跨过零，不作普遍加速保证。单个大 LOD 的回退稳定，约增加 40–50 ns；其余图案大多接近噪声。保留这两项改动的依据是去除不必要的排序和重复扫描、逆序输入的可复现收益，以及明确披露的存储和小输入代价。

本次本地成对测量代码和原始 CSV 保存在忽略目录 `target/algorithm-comparison/`。保留该目录时可重跑：

```powershell
cargo run --release --manifest-path target/algorithm-comparison/Cargo.toml --target-dir target/algorithm-comparison/build
```

长期基准入口为 `cargo bench --bench worst_case`。再次比较版本时应保留相同输入、交替运行，并检查小输入的稳定回退，不能只选有利的单次数字。

## 验证

`cargo test --all-features` 和 `cargo test --release --no-default-features` 均通过，每种配置为 42 项单元测试和 5 项资源测试；`cargo clippy --all-targets --all-features -- -D warnings`、`cargo fmt --check`、`git diff --check` 均通过。

新增验证包括 5,504 个二分图与合法部分匹配组合对重扫预热实现、同一左顶点连续迁移、混合 LOD 的 26 种输入顺序、重复起点和不同起点重叠、失败后复用与坐标 63／终点 64。现有全部 65,536 个 4×4 二分图的最优性证书、全部 `3^9` 个 3×3 彩色像素图的独立分区 oracle、零分配和四 worker 栈测试均保持通过。

# Chord 提取与匹配后端

前端按最大同色区间提取 chord，后端线性构建有序 CSR 并执行精确匹配。
各颜色组独立处理，含孔区域走同一条精确路径。

原始 leaves 和预校验 image 入口共用行桶构造轴区间，省去独立的事件排序和活跃集合。
边长 s 的 leaf 在每方向写入 s 个区间；合法图像中 Σs≤Σs²≤n²，不增加容量或渐近复杂度。

## 从最大区间直接判定凹角

轴区间构建会合并每行相邻的同色段。相邻两行的最大区间 a、b 能产生水平 chord，
当且仅当二者颜色相同、交集非空、起点不同且终点不同；chord 就是它们的交集。

交集内部两侧均为同色。交集起点左侧恰有一个同色像素，当且仅当两段起点不同：
晚开始的区间不可能再向左延续同色，否则它就不是最大区间。因此起点周围恰有三个
同色像素，形成支持向右延伸的凹角。终点同理。交换横纵坐标即得到竖直情形。
这个判定不依赖区域是否连通或含孔，也无需再次查询四邻像素。

两个方向共用一份双指针扫描。终点相等时两段均已耗尽，同时推进两个指针，跳过
原先多扫描的空交集。生成的 chord 及其顺序不变；扫描总计 O(n²)，后续颜色排序不变。
测试保留原四像素凹角判定作为独立参考，穷举 3^8 种相邻行局部图案并覆盖图像边界。

## 有序 CSR 的线性构建

格点建图按竖直 chord 编号依次生成冲突边，因此边缓冲中每个右顶点的边连续存放。
由右度数的前缀和可定位各段；再稳定计数排序全部右顶点，按该顺序将边散布到左 CSR。
得到的每个邻接表与原先按 `(右度数, 右编号)` 比较排序的结果相同。

边长为 n 时右度数不超过 n−1，因此构建为 O(C+E+n)，C 是 chord 数，E 是冲突数。
64×64 使用 64 个计数桶。`right_layout` 缓冲分成右边段起点和排序结果两部分，均预分配。
修改边生成逻辑时，必须保持按右顶点连续分组这一条件。

格点编号的有效性由列标记和列内 y 位图共同确定；没有额外的逐格点标记数组。
列标记回绕时只需清零列标记。每轮清空全部列位图的替代方案在大量小颜色组下有回退，未采用。

选出的切线直接按 OR 合入分区掩码，顺序不影响结果，因此不再排序。
公开的 profiling 字段 `sort_cuts` 为兼容保留，值始终为零。

## HKDW 搜索

保留已有贪心初始化和长度 3 增广。贪心生成的转置 CSR 随后供反向 BFS 使用。

每轮先从全部空闲右顶点反向遍历交替路径，找到最短层上的空闲左顶点；DFS 沿层次递减搜索，
得到极大的顶点不相交最短增广路径集。随后从其他尚未访问的空闲左顶点追加 DFS。
两段 DFS 共享本轮访问标记，成功路径及失败搜索访问过的左顶点均不重复展开。
下一轮重新建立层次并清除访问标记，失败根可以再次搜索。

匹配中的已访问右顶点始终配对到某个已访问左顶点，空闲右顶点一旦使用也满足该条件，
因此只需一套左顶点访问标记即可保持路径不相交。每轮扫描 O(C+E)，并保留 HKDW 的
O(√C) 轮数上界。参考 Duff、Kaya、Uçar 的
[Design, Implementation, and Analysis of Maximum Transversal Algorithms](https://epubs.stfc.ac.uk/manifestation/5901/RAL-P-2010-001.pdf)，第 3.3.2 节。

DFS 用显式栈记录左顶点及继续搜索的位置，不依赖递归调用栈。
反向 BFS 的可达标记不能直接用于原有独立集公式；最大匹配完成后，从空闲左顶点沿交替路径
重新求可达集合 Z，选择 `H∩Z` 与 `V\Z`。普通入口和 profile 入口共用这些算法步骤。

## 复杂度与资源

像素图满足 C=O(n²)、E≤(n−1)²、最大度 Δ≤n−1。保留的长度 3 预热上界为 O(C+EΔ)，
HKDW 搜索为 O((C+E)√C)，加上前端 O(n² log n) 的排序上界，整体仍为 O(n³)。
本次没有引入单调游标、度 1 递归消除、跨颜色统一匹配或坐标位图匹配。

固定数组包括 2C 个 CSR 布局项、至多 E 个最短层根（允许重复）、C 级的队列和显式栈。
所有数组均内联在 scratch 中复用，初始化及借用分解不调用堆分配器。
可达数组在每轮作为访问标记，最终改为独立集可达标记。容量证明见 [栈 scratch](scratch.md)。

## 回归校验

- 全部 65,536 个 4×4 二分图与独立穷举匹配比较，并校验等大小的顶点覆盖证书。
- 长度不同的不相交增广路径、竞争最短路径后的跨轮重试、非对称/空图的缓存复用。
- 2,047 条边的单条增广路径和 3,969 个重复 BFS 根的预分配边界。
- 有序 CSR 与比较排序的逐项一致性，涵盖空顶点、度数相同以及度数 63。
- 两个不同颜色的含孔像素图，校验最优矩形数、颜色、完整覆盖和无重叠。

性能结论应使用完整分解测量；单轮扫描更少并不保证总耗时更短。
